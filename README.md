# quiz-ch7-9

「AI응용 데이터 관리」 7장(영화 데이터 분석)과 9장(Plotly 시각화) 시험 대비용 개인 학습 앱입니다. 개념 카드(코드 전후 예시, 실제 데이터로 그린 그래프, 비교표), O/X·객관식 문제 30문항, 오답노트, 모의고사(O/X 3 + 객관식 7)가 들어 있습니다.

- 문제의 코드 결과는 pandas로 실행해 검증했습니다(`python -X utf8 tools/verify.py`).
- 카드의 그래프 숫자는 imdb_top_1000.csv, delivery_orders.csv에서 집계한 값입니다(`tools/build_content.py`). 원본 CSV와 강의자료는 저장소에 없습니다.
- 내용을 고치면 `sw.js`의 `VERSION`을 올려야 휴대폰에 새 버전이 반영됩니다.
